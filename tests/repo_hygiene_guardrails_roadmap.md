\# Repo Hygiene Guardrails Roadmap



\## Stav

\- runner je zmrazený na manifest-driven režim

\- nové testy sa majú pridávať po batchoch

\- runner sa nemá prepisovať pri každom malom teste



\## Batch 1 — hotovo

\- source\_of\_truth presence

\- source\_of\_truth json valid

\- forbidden tracked artifacts baseline-aware

\- canonical lineage minimum

\- canonical truth consistency

\- canonical reference separation

\- canonical product export contract

\- canonical json schema shape

\- canonical consumer scope rules

\- canonical decision vs reference boundaries

\- canonical upstream paths exist

\- canonical filename/path contracts

\- canonical required top-level keys

\- canonical reference truth flags

\- canonical decision ids present

\- canonical manifest indexes shape

\- canonical truth domain allowed values

\- canonical artifact type allowed values

\- canonical truth status allowed values

\- canonical consumer scope allowed values

\- canonical notes blocks present

\- canonical manifest schema version present

\- canonical decision summary blocks present

\- canonical reference summary blocks present

\- canonical decision scope lists are strings

\- canonical reference rule lists are strings

\- output registry official truth flags

\- manifest validity



\## Batch 2 — najbližší krok

\- canonical decision summary required keys

\- canonical reference summary required keys

\- canonical manifest required keys

\- canonical export contract required keys

\- canonical dates string shape

\- canonical ids uniqueness



\## Batch 3 — potom

\- registry cross-reference checks

\- script registry path existence

\- output registry path existence

\- output registry script linkage sanity

\- source\_of\_truth vs registry consistency



\## Pravidlá

\- nové testy sa pridávajú po batchoch

\- runner sa nemení mimo manifest/roadmap režimu

\- raw automation/research files sa nemiešajú do hygiene commitov

\- source\_of\_truth ostáva jediný official SSOT

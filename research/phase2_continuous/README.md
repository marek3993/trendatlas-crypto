# Phase 2 continuous development

This is a separate, research-only development line. The 2026-09-27 `SEALED`
experiment is read-only evidence. Outer OOS and the prospective 2027 period are
absent from the runner's input. Candidate scores use four chronological inner
validation folds that end in April 2022. Historical daily spot bars are proxies;
the scores are not venue-certified and cannot promote a production strategy.

The two-worker service evaluates the five predeclared families with next-open
fills, conservative costs, double-cost and delayed-entry replays, complete
position-episode concentration, and adjacent-parameter checks. Pareto selection
uses only development results. The separate networked broker receives sanitized
parent summaries, validates exact genes, and falls back to a deterministic
mutation for unavailable or invalid proposals. The worker has no network or
credential access; the broker has no market-data or account access.

SQLite stores unique evaluation keys, immutable completed results and an
append-only hash-chained event ledger. A bounded activation resumes after a
crash or reboot; the timer creates a distinct successor when a cycle completes.
The finite predeclared parameter space is not silently expanded or retested:
when genuinely new hypotheses are exhausted, the runner records
`SPACE_EXHAUSTED` and requires a new research contract or fresh development data.

The public-data collector remains a separate archive. Its documentation fix
uses current official URLs without `.md`, retry and backoff. Missing prose is a
warning; missing market observations remain missing. The explicit manifest
migration preserves the existing append-only observation chain.

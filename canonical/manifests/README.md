\# MRV1 Canonical Manifests



Sem patria canonical manifests a lineage manifests.



\## Účel

Manifest má hovoriť:

\- čo artifact je

\- aký má type

\- aký má truth domain

\- aký má truth status

\- z čoho vznikol

\- kto ho má čítať



\## Pravidlá

\- manifest nemení truth potichu

\- manifest opisuje contract a lineage

\- manifest nemá suplovať decision

\- manifest má byť machine-readable tam, kde to dáva zmysel



\## Príklady budúcich súborov

\- `canonical\_artifacts\_manifest.json`

\- `canonical\_strategy\_manifest.json`

\- `canonical\_lineage\_manifest.json`

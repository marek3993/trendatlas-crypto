\# MRV1 Canonical References



Sem patria schválené referenčné artefakty.



\## Účel

Reference artifact je:

\- stabilný

\- schválený

\- vhodný na porovnanie

\- ale nie je current official live truth, ak to nie je explicitne povedané



\## Pravidlá

\- reference sa nesmie tváriť ako official live state

\- reference musí mať truth\_status = reference

\- reference má mať lineage minimum

\- reference má byť oddelený od exploratory compare outputs
